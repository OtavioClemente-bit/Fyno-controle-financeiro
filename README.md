# Fyno - Controle Financeiro

**Fyno** é um aplicativo de controle financeiro pessoal desenvolvido em **Flutter** e **Dart**, com foco em organização financeira, registro de movimentações e acompanhamento de evolução patrimonial.

O projeto foi pensado para ajudar pessoas que ainda controlam suas finanças por anotações soltas, planilhas desorganizadas ou apenas pela memória.

---

## Status do projeto

🚧 **Em desenvolvimento**

Este repositório está sendo estruturado aos poucos, com foco em criar uma base limpa, organizada e evolutiva para um aplicativo real de finanças pessoais.

---

## Objetivo

Criar uma ferramenta simples e acessível para:

- Registrar receitas e despesas
- Organizar gastos por categoria
- Acompanhar investimentos
- Controlar movimentações financeiras
- Gerar uma visão mais clara da vida financeira do usuário
- Apoiar decisões melhores sobre uso do dinheiro

---

## Funcionalidades planejadas

- Cadastro de receitas
- Cadastro de despesas
- Categorias personalizadas
- Registro de investimentos
- Controle de veículos e abastecimentos
- Relatórios financeiros
- Acompanhamento de carteira
- Banco de dados local
- Leitura e conferência de comprovantes
- Tela inicial com resumo financeiro
